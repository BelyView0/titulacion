Conexión a la base de datos

Configure SQLite (instalación local) o PostgreSQL (producción). La configuración se guarda en config/database.json.

Migración automática de datos
  • Primero se prueba la conexión a la nueva base de datos.
  • Solo si la conexión es segura se migran los datos actuales al destino.
  • La nueva configuración no se guarda si falla la conexión o la migración; se mantiene la BD actual.
  • El destino debe estar vacío (sin datos de la aplicación). Si vuelve a SQLite y ya existe un db.sqlite3 con datos viejos, renómbrelo o elimínelo antes.
  • Los archivos en media/ (PDFs, fotos, etc.) no se copian; solo viajan las rutas en la base de datos.
  • Al terminar con éxito debe reiniciar el servicio del sistema.
